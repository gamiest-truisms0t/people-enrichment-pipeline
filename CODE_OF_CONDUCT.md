# Code of conduct

Everyone taking part in this repository's issues, pull requests and discussions is expected
to be respectful and constructive: assume good faith, criticise the work rather than the
person, and keep real people's data out of examples. The pipeline enriches real people, so
fixtures and demo files use synthetic data or public figures only.

Harassment, discrimination and publishing someone's private information are not acceptable.
Report a problem by contacting the maintainer directly on GitHub; reports are handled in
confidence. The maintainer may edit, remove or lock contributions that break these rules.
