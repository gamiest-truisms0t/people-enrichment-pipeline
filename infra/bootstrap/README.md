# bootstrap

Applied once per account with `make bootstrap`, with local state on purpose because there
is nowhere else to keep it yet: the bucket every other stack stores its Terraform state in,
the account-level S3 public access block, and the GitHub OIDC provider with the three
deploy roles (`plan`, `readonly`, `apply`) whose trust policies are pinned to this
repository's immutable subject. The variables that identify the repository are the ones
to override on another account.

The tables below are generated by terraform-docs (`make tf-docs`).
