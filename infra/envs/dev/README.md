# envs/dev

The `dev` environment: the composition of the five modules plus the resources that are
naturally environment-wide (the alerts topic, the dead-letter queue, the credit and
dead-letter alarms, the dashboard, the AWS Budget, the Cost Anomaly Detection subscription,
the IAM Access Analyzer). `make init` points it at the state bucket from the bootstrap
stack, `make plan` and `make apply` package the Lambda code first, and the variables below
are the knobs an operator turns: credit ceilings, guard thresholds, retention, the
freshness objective. Settings for this account live in `terraform.tfvars` (git-ignored;
see `terraform.tfvars.example`).

The tables below are generated by terraform-docs (`make tf-docs`).
