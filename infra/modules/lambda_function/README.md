# lambda_function

One Lambda function with everything it needs and nothing shared: its own execution role
(logging, metrics and tracing plus the policy the caller passes in), an explicit log group
with retention, X-Ray tracing, an optional dead-letter queue, an error alarm, and an
optional VPC attachment for accounts that require it.
