# orchestration

The Step Functions Standard workflow that runs one batch (`pipeline.asl.tftpl`: validate,
Map over rows, build curated, notify), the EventBridge rule that starts it when a CSV
lands under `incoming/` in the landing bucket, their IAM roles, the vended log group, and
the three state-machine alarms (executions failed, timed out, execution time above the
freshness objective). The alerts topic is created by the caller so the Lambda alarms can
share it.
