# secrets

The provider API key as an SSM SecureString encrypted with the AWS-managed `aws/ssm` key.
Terraform creates the parameter with a placeholder through the provider's write-only
argument, so the real value never enters Terraform state; `make set-api-key` writes it out
of band, and the functions read it at run time.

The tables below are generated by terraform-docs (`make tf-docs`).
