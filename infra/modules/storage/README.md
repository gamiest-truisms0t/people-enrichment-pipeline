# storage

The landing and data buckets and the DynamoDB state table. Both buckets get the same
hardening (bucket-owner ownership, public access block, versioning, SSE-S3, a TLS-only
policy, EventBridge notifications) and their own lifecycle rules; the data bucket's policy
also denies deletes under `raw/` for every principal except the ones listed in
`raw_delete_principal_arns`. The table holds the lookup cache, the credit counters, the
batch claims and the provider circuit breaker, in provisioned capacity inside the
always-free allowance.

The tables below are generated by terraform-docs (`make tf-docs`).
